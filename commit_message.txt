Refactor: Modernize Python typing and features in rpcplugin

- Modernized typing:
    - Replaced `typing.Any` with `object` where appropriate.
    - Ensured usage of modern union (`X | Y`) and optional (`X | None`) syntax.
    - Verified built-in types (`dict`, `list`, `tuple`) are used for hints instead of `typing` equivalents.
- Ensured use of f-strings for string formatting.
- Reviewed for opportunities to use modern Python features like match/case.
- Linted and auto-formatted the codebase using Ruff (`ruff check --fix --unsafe-fixes`). Output in `ruff_output.txt`.
- Performed static type checking using MyPy. Output in `mypy_output.txt`.
    - One known MyPy issue remains in `src/pyvider/rpcplugin/config.py`
      (L302: Unsupported right operand type for in ("object")) despite
      multiple attempts to resolve it with casts and type guards.

    - Full coverage runs in earlier subtasks also timed out.
    - Due to these issues, a successful test run for the rpcplugin changes could not be completed in this environment.
