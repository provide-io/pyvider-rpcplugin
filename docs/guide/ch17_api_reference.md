# Chapter 17: API Reference

This chapter provides a reference for the key public classes, functions, and interfaces in the `pyvider.rpcplugin` library.

## Core Client Components

### `pyvider.rpcplugin.client.RPCPluginClient`

The main class for host applications to manage and interact with plugin executables.

*   **`__init__(self, command: list[str], config: dict[str, Any] | None = None)`**
    *   **Purpose**: Initializes the plugin client.
    *   **Parameters**:
        *   `command: list[str]`: A list representing the command and its arguments to execute the plugin server (e.g., `['python', 'my_plugin.py']`).
        *   `config: dict[str, Any] | None` (optional): A dictionary for client-specific or plugin subprocess configuration.
            *   If `config` contains an `'env'` key, its value (a dictionary) will be used to update the environment variables for the launched plugin subprocess.
            *   Other keys might be used for future client-side configurations.
*   **`async start(self) -> None`**
    *   **Purpose**: Launches the plugin subprocess, performs the handshake protocol, establishes a secure gRPC channel, and initializes internal service stubs. This method must be called and awaited before making RPC calls.
    *   **Raises**: `TransportError`, `HandshakeError`, `ProtocolError`, `SecurityError`, or other `RPCPluginError` subclasses on failure to launch, handshake, or connect.
*   **`async close(self) -> None`**
    *   **Purpose**: Gracefully shuts down the connection to the plugin. This includes requesting the plugin server to shut down (via the controller service), terminating the plugin subprocess if it's still running, and closing the transport and gRPC channel. Idempotent.
*   **`grpc_channel: grpc.aio.Channel | None`** (Attribute)
    *   **Description**: The `grpc.aio.Channel` instance established after a successful `start()` call. This channel should be used to create your service-specific gRPC stubs for making RPC calls to the plugin. It is `None` before `start()` or if `start()` fails.
*   **`is_started: bool`** (Attribute)
    *   **Description**: A boolean flag that is `True` if the client has successfully started, completed the handshake, and established the gRPC channel. `False` otherwise.
*   **`target_endpoint: str | None`** (Attribute)
    *   **Description**: The actual network address (e.g., `unix:/tmp/socket.sock` or `127.0.0.1:12345`) the client connected to after a successful handshake. `None` before connection.

## Core Server Components

### `pyvider.rpcplugin.server.RPCPluginServer`

The main class used within a plugin executable to run the RPC server, manage the handshake, and serve RPC requests.

*   **`__init__(self, protocol: RPCPluginProtocol, handler: Any, config: dict[str, Any] | None = None, transport: RPCPluginTransport | None = None)`**
    *   **Purpose**: Initializes the plugin server.
    *   **Parameters**:
        *   `protocol: RPCPluginProtocol`: An instance of your custom class that implements the `RPCPluginProtocol` interface. This tells the server how to set up your gRPC services.
        *   `handler: Any`: An instance of your gRPC service handler (the servicer class generated by `grpc_tools` that contains your RPC method implementations).
        *   `config: dict[str, Any] | None` (optional): A dictionary for server-specific configuration overrides. If `None`, global `rpcplugin_config` is used.
        *   `transport: RPCPluginTransport | None` (optional): A pre-configured transport instance (e.g., `TCPSocketTransport`, `UnixSocketTransport`). If `None`, the server will attempt to negotiate and set up a transport based on global configuration (`PLUGIN_SERVER_TRANSPORTS`, `PLUGIN_SERVER_ENDPOINT`).
*   **`async serve(self) -> None`**
    *   **Purpose**: Starts the plugin server. This method performs the server-side handshake (validates magic cookie, determines transport, prints handshake string to `stdout`), sets up the chosen transport, starts the internal gRPC server, and then blocks, serving requests until `stop()` is called or a shutdown signal is received.
*   **`async stop(self) -> None`**
    *   **Purpose**: Gracefully stops the gRPC server, closes the transport, and cleans up any associated resources. Idempotent.
*   **`async wait_for_server_ready(self, timeout: float = 5.0) -> None`**
    *   **Purpose**: An awaitable utility that resolves only when the server has successfully started, bound to its port/socket, and the internal gRPC server is ready to accept connections. Useful for synchronization, especially in tests or managed environments.
    *   **Parameters**:
        *   `timeout: float`: Maximum time in seconds to wait for readiness.
    *   **Raises**: `asyncio.TimeoutError` if the server does not become ready within the timeout. `TransportError` if a readiness check fails.

## Protocol Definition

### `pyvider.rpcplugin.protocol.base.RPCPluginProtocol`

An abstract base class that your custom protocol implementations must inherit from.

*   **`async get_grpc_descriptors(self) -> tuple[Any, str]`** (Abstract method)
    *   **Purpose**: Provide the necessary information for the `RPCPluginServer` to find and register your gRPC service(s).
    *   **Returns**: A tuple `(descriptor_module, service_name_str)`.
        *   `descriptor_module`: The Python module generated by `grpc_tools` from your `.proto` file that ends with `_pb2_grpc.py`. This module contains the service descriptor and the `add_YourServiceServicer_to_server` function.
        *   `service_name_str`: The fully qualified name of your service as defined in the `.proto` file (e.g., `"mypackage.MyService"`).
*   **`async add_to_server(self, server: grpc.aio.Server, handler: Any) -> None`** (Abstract method)
    *   **Purpose**: Register your gRPC service servicer (handler) with the `grpc.aio.Server` instance.
    *   **Parameters**:
        *   `server: grpc.aio.Server`: The gRPC server instance managed by `RPCPluginServer`.
        *   `handler: Any`: Your service handler instance (the servicer).
    *   **Implementation**: Should call the `add_YourServiceServicer_to_server(handler, server)` function that was generated by `grpc_tools`.

## Factory Functions

### `pyvider.rpcplugin.factories`

Module containing convenience factory functions.

*   **`plugin_client(command: list[str], config: dict[str, Any] | None = None) -> RPCPluginClient`**
    *   **Purpose**: Creates an `RPCPluginClient` instance, typically for launching a plugin executable.
    *   (Parameters are the same as `RPCPluginClient.__init__`)
*   **`plugin_server(protocol: RPCPluginProtocol, handler: Any, transport: str = "unix", transport_path: str | None = None, host: str = "127.0.0.1", port: int = 0, config: dict[str, Any] | None = None) -> RPCPluginServer`**
    *   **Purpose**: Creates an `RPCPluginServer` instance, automatically configuring its transport based on the provided parameters.
    *   **Parameters**:
        *   `protocol`, `handler`, `config`: Same as `RPCPluginServer.__init__`.
        *   `transport: str`: Specifies transport type, `"unix"` or `"tcp"`. Default is `"unix"`.
        *   `transport_path: str | None`: Path for Unix domain socket.
        *   `host: str`: Host for TCP socket. Default `"127.0.0.1"`.
        *   `port: int`: Port for TCP socket. Default `0` (ephemeral port).
*   **`plugin_protocol(protocol_class: type | None = None, service_name: str | None = None, **kwargs: Any) -> RPCPluginProtocol`**
    *   **Purpose**: Creates an instance of an `RPCPluginProtocol`.
    *   **Parameters**:
        *   `protocol_class: type | None`: The class implementing `RPCPluginProtocol`. If `None`, returns an instance of `BasicRPCPluginProtocol` (a minimal, no-op protocol).
        *   `service_name: str | None`: If `protocol_class` is `None`, this name is used for the `BasicRPCPluginProtocol`. If `protocol_class` is provided, this argument might be passed to its constructor if it accepts `service_name_override`.
        *   `**kwargs`: Additional arguments passed to the constructor of `protocol_class`.

## Configuration

### `pyvider.rpcplugin.config.RPCPluginConfig`

A singleton class that manages all `PLUGIN_` prefixed configurations. Access via `rpcplugin_config = RPCPluginConfig.instance()`.

*   **`get(self, key: str, default: Any = None) -> Any`**: Retrieves a configuration value.
*   **`get_list(self, key: str) -> list[Any]`**: Retrieves a configuration value, ensuring it's a list.
*   **`set(self, key: str, value: Any) -> None`**: Dynamically sets or overrides a configuration value. Performs type conversion based on `CONFIG_SCHEMA` if the key is known.
*   Helper properties like `magic_cookie_key()`, `auto_mtls_enabled()`, `handshake_timeout()`, etc., provide convenient access to common settings.

### `pyvider.rpcplugin.config.configure(...)`

A utility function for programmatically setting multiple common configuration options at once.
Example: `configure(magic_cookie="secret", auto_mtls=True, handshake_timeout=20.0)`
Refer to Chapter 18 (Configuration Variables) for details on parameters.

## Cryptography

### `pyvider.rpcplugin.crypto.Certificate`

A class for generating, loading, and managing X.509 certificates and private keys for mTLS.

*   **`__init__(self, cert_pem_or_uri: str | None = None, key_pem_or_uri: str | None = None, generate_keypair: bool = False, key_type: str = "ecdsa", ...)`**:
    *   Loads a certificate/key from PEM strings or `file:///` URIs.
    *   If `generate_keypair=True`, generates a new self-signed certificate and key.
*   **`@classmethod create_ca(cls, common_name: str, ...)`**: Creates a new self-signed CA certificate.
*   **`@classmethod create_signed_certificate(cls, ca_certificate: Certificate, common_name: str, ...)`**: Creates a new certificate signed by the provided `ca_certificate`.
*   **`@classmethod create_self_signed_server_cert(cls, common_name: str, ...)`**: Creates a self-signed certificate suitable for a server (e.g., with serverAuth EKU).
*   **Properties**:
    *   `.cert: str`: The certificate in PEM format.
    *   `.key: str | None`: The private key in PEM format (if available).
    *   `.is_valid: bool`: True if the certificate is currently valid by date.
    *   `.is_ca: bool`: True if the certificate is marked as a CA.
    *   `.subject: str`: The certificate's subject distinguished name.
    *   `.issuer: str`: The certificate's issuer distinguished name.
    *   `.public_key: PublicKey | None`: The public key object.
    *   `.serial_number: int | None`: The certificate's serial number.
*   **`verify_trust(self, other_cert: Certificate) -> bool`**: Verifies if `other_cert` is trusted based on `self.trust_chain`.

## Exceptions

### `pyvider.rpcplugin.exception`

Module containing custom exceptions. All inherit from `RPCPluginError`.

*   **`RPCPluginError(Exception)`**: Base class.
*   **`ConfigError(RPCPluginError)`**: Configuration-related errors.
*   **`HandshakeError(RPCPluginError)`**: Errors during the client-server handshake.
*   **`ProtocolError(RPCPluginError)`**: Violations of the `pyvider.rpcplugin` communication protocol (not gRPC level).
*   **`TransportError(RPCPluginError)`**: Errors related to the underlying network transport (sockets, connections).
*   **`SecurityError(RPCPluginError)`**: Base for security-related errors.
    *   **`CertificateError(SecurityError)`**: Errors specific to certificate loading, generation, or validation.
